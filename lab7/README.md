## Outcome: Write a program that implements fundamental image processing algorithms.

This lab is about sharpening and noise removal. Part A covers the Laplacian filter for sharpening, and Part B covers adding noise (Gaussian, salt & pepper, exponential, uniform) and removing it with mean filters (arithmetic, geometric, harmonic, contra-harmonic) and order-statistic filters (median, max/min, midpoint). Both parts are also applied to a colored image.
