## Outcome: Write a program that implements fundamental image processing algorithms.

This lab is about edge detection. It covers the Sobel, Roberts, Prewitt, Canny, multi-channel Canny, LoG, DoG and color gradient detectors. The tasks apply Sobel, Prewitt and Canny to a new image (Butterfly.jpg) and compare the Canny results for the threshold pairs (30, 90), (50, 150) and (100, 200).
